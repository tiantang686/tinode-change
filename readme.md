# Tinode 本地聊天使用说明

## 启动与登录

双击本目录的 `Start-Tinode.cmd`，它会启动本地 PostgreSQL 和 Tinode 后端。开发前端在 `frontend` 目录用 `npm.cmd run dev` 启动。打开 http://127.0.0.1:5176/。如果前端依赖尚未安装，在该目录先运行 `npm.cmd ci`。后端端口为 6060，数据库端口为 55432。启动脚本使用包含群聊撤回修改的 `server/tinode-recall.exe`，后端修改在 `chat-0.25.5/server/topic.go`。

可用本地演示账号 `alice / alice123`、`bob / bob123` 登录。也可点击「注册」，输入唯一用户名、密码和显示名称。注册无需邮箱、短信或邀请码。可以在另一个浏览器或无痕窗口登录第二个账号。

## 会话和联系人

| 功能 | 操作 |
| --- | --- |
| 按用户名找人 | 点击左侧「搜索用户名」，输入完整登录用户名，按 Enter。邮箱、号码和别名仍可用于搜索已有对应信息的用户。 |
| 发起私聊 | 点击搜索结果打开对话并发消息。对方可在收到邀请后接受、忽略或屏蔽。 |
| 群聊和频道 | 点击新会话图标，切到新群组，填写名称并按需选择频道。通过会话资料管理成员。频道读者和群聊成员权限不同。 |
| 浏览会话 | 左侧列表显示头像、最后消息、时间、未读数和在线状态。点列表项进入聊天。 |
| 会话管理 | 会话菜单提供置顶、归档、静音、屏蔽和删除等操作，实际选项取决于会话类型及权限。 |
| 会话资料 | 打开聊天后点击顶部「会话资料」，查看成员和个人信息。管理员可以按权限管理成员。 |
| 已保存的消息 | 打开「已保存的消息」，用于给自己发送内容。 |

## 发消息和管理记录

- 在底部输入文字，点击发送或使用设置里的发送快捷键。中文输入法组词期间按 Enter 不会触发发送。未发送的草稿按本机账号和会话保存。
- 表情按钮打开 40 个小表情的网格。「最近」显示这一输入面板使用过的表情。点击表情插入光标处，点击面板外关闭。受支持的表情在 Tinode 消息气泡中显示为相同图案。
- 可用附件按钮发送图片、视频和文件，设备及站点权限允许时可录制语音。访问剪贴板或麦克风需浏览器许可。
- 右键消息可以引用、转发、删除、编辑或置顶。可见菜单取决于消息类型、发送状态、作者和当前权限。普通删除仅影响自己的记录，管理删除可能影响所有人。
- 对自己发送且仍在两分钟内的消息，右键选「撤回」。普通群成员可以撤回自己的消息，服务端验证作者和时间。私聊仍按该会话权限执行。在线聊天窗口收到撤回事件后，会在消息区居中显示提示。历史记录重新加载后不会恢复本次新增的提示姓名。
- 会话顶部搜索按钮可搜索已加载的聊天记录，点结果跳到对应消息。更早的记录需要先向上滚动加载。

## 界面与账户

- 顶部主题下拉框可切换深空蓝、银白玻璃、紫电、石墨与薄荷、钴蓝与琥珀。浏览器会记住选择。
- 设置中可调整账户资料、消息声音、文字大小、快捷键及通知等选项。通知被浏览器拒绝时仍可登录。本地后端未配置推送服务、语音和视频通话所需的完整服务。
- 顶部「退出登录」清除本机登录凭据并返回登录页。

## 检查中发现并处理的问题

| 问题 | 修改与效果 |
| --- | --- |
| 普通群成员发出的消息没有撤回入口 | 服务端按作者和两分钟窗口处理群聊撤回，不给普通成员授予删除他人消息的权限。双账号 WebSocket 测试验证了本人撤回和他人消息被拒绝。 |
| 表情选择器与聊天气泡的显示不同 | 选择器和消息共用同一份表情映射及图案，存储与传输仍使用 Unicode。 |
| 表情布局挤压和悬停变暗 | 独立约束格子尺寸，悬停用描边，支持点击外部关闭。 |
| 删除事件只让气泡消失 | 增加实时居中提示，发送方显示「你撤回了一条消息」，其他在线参与者根据事件显示发送方名称。现有数据库不保存这条界面提示。 |
| 刷新时恢复订阅缓存报错 | 本机热更新环境绕过有缺陷的 IndexedDB 恢复路径，换开发端口也生效。 |
| 拒绝通知权限时出现登录错误 | 通知初始化失败由通知流程处理，阻止通知不阻止登录。 |
| 好友通知可能缺少联系人数据 | 先刷新列表，再在联系人数据可用时更新会话状态。 |

功能变更和测试结果见 [historychange.md](historychange.md)。

## 本轮验证范围

- 使用 Alice 和 Bob 两个独立 Chrome 会话验证登录、五套主题切换和退出。
- 在浏览器验证用户名查找与打开私聊、草稿刷新后重新登录恢复、会话内记录搜索、表情网格及外部关闭、发送后气泡显示相同小表情、自身撤回后出现居中提示。
- 通过真实后端协议验证普通群成员撤回本人消息、群主收到删除事件、成员不能撤回他人消息。该检查使用临时测试群。
- 文件、图片、视频、录音、合并转发、各类群管理权限和通知服务未逐项进行端到端测试。语音与视频通话依赖额外服务配置。

前端开发服务保留 JSX 热更新。手动修改静态 CSS 或 HTML 后，刷新浏览器查看效果。

## 从 GitHub 克隆后首次搭建

仓库包含前端源码、修改后的 Go 后端和配置示例。需要本机安装 Node.js（参见 frontend/package.json）、Go（参见 chat-0.25.5/go.mod）和 PostgreSQL。将 PostgreSQL 配置为监听 127.0.0.1:55432，并在配置文件中填写实际数据库凭据。

在仓库根目录执行 PowerShell 命令：

```powershell
Copy-Item server/tinode.conf.example server/tinode.conf
Copy-Item chat-0.25.5/server/templ server/templ -Recurse
Push-Location chat-0.25.5
go build -tags postgres -ldflags '-X main.buildstamp=v0.25.5' -o ../server/tinode-recall.exe ./server
go build -tags postgres -o ../server/init-db.exe ./tinode-db
Pop-Location
```

编辑 `server/tinode.conf` 后，在 `server` 目录运行一次 `./init-db.exe` 初始化数据库，再运行 `./tinode-recall.exe -static_data=../frontend`。在另一个终端进入 `frontend`，运行 `npm.cmd ci` 和 `npm.cmd run dev`，打开 http://127.0.0.1:5176/ 注册账号。演示账号取决于初始化时是否导入官方演示数据。`Start-Tinode.cmd` 适用于已经按本地部署结构准备好便携 PostgreSQL 的机器。
